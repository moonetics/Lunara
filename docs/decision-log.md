## 2. Mengapa Eksekusi Bertahap (Phased Prompts) Lebih Unggul dari 1 Prompt Raksasa?

Dalam pengembangan software dengan AI Coding Agent:
- **Kelemahan 1 Prompt Raksasa**: AI dipaksa membuat 25+ file sekaligus. Hasilnya sering kali kode terpotong di tengah jalan (*truncated*), implementasi method kosong (`// TODO: implement later`), dan banyak bug integrasi antar-komponen.
- **Keunggulan Prompt Per-Fase (*Phased Modular Execution*)**:
  1. **Fokus Tajam**: AI fokus menyelesaikan 1 modul spesifik (misal: Engine Siklus) sampai tuntas dengan unit test.
  2. **Dapat Diuji Langsung**: Anda bisa menjalankan `flutter run` setelah setiap fase untuk memastikan fitur berjalan mulus sebelum lanjut ke fase berikutnya.
  3. **Zero Hallucination**: Menjaga konteks AI tetap segar dan bebas kebingungan dependensi.
